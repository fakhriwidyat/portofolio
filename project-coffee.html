Stemla Coffee Shop

WEB DEVELOPMENT • UI/UX DESIGN

Project Overview

A single-page landing page for a specialty coffee shop concept, "Stemla Coffee Shop." The project focuses on a warm minimalist aesthetic, clean code architecture, and a fully responsive layout that highlights the brand's product and atmosphere.

My Role & Challenges

Working as the Frontend Developer, I was responsible for refactoring an initial single-file prototype into a clean, maintainable codebase—separating markup, styling, and logic into their own files. The biggest challenge was restructuring the code without breaking the Tailwind CDN workflow, while also improving accessibility and adding real functionality (like a working mobile navigation menu) that was missing from the original design.

Technologies Used

HTML, Tailwind CSS, and JavaScript.
